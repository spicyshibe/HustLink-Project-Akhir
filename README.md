## 📌 Deskripsi Project
HustLink adalah aplikasi berbasis web yang dikembangkan sebagai bagian dari Project Akhir Teknologi Server.  
Project ini berfokus pada **penerapan arsitektur server**, **containerization**, serta **kolaborasi tim menggunakan Git & Docker**.
Aplikasi ini dibuat untuk mengatasi penyebaran informasi lowongan pekerjaan internal
yang sering kali tidak terpusat (hanya melalui pesan singkat atau grup chat) sehingga
mudah tertumpuk dan sulit dicari kembali. Dengan portal ini, seluruh informasi lowongan,
kualifikasi, dan status rekrutmen dapat diakses secara transparan dan rapi oleh seluruh
anggota organisasi atau perusahaan.

Tujuan utama:
- Menerapkan deployment aplikasi menggunakan Docker
- Menggunakan Nginx sebagai reverse proxy
- Mengelola database MySQL secara terstruktur
- Menerapkan workflow Git (branch & merge request)

---

## 🧱 Arsitektur Sistem
Project ini menggunakan arsitektur **multi-container**:

- **Node.js (Express)** → Backend Application  
- **MySQL** → Database Server  
- **Nginx** → Reverse Proxy  
- **Docker Compose** → Orchestration
